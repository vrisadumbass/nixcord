# Demo assets

Images used by `--demo` mode only (see `crates/nixcord-app/src/demo_assets.rs`). They are
read from disk at runtime and are not compiled into the exe. Every file below was resized,
cropped and/or recompressed for size; nothing else was changed unless noted.

No file shows a real, identifiable person, and none comes from Discord.
